## Análisis antes de reportar

| Pregunta | Hallazgo |
|---|---|
| ¿Qué impacto tiene sobre el criterio de aceptación? | |
| ¿En qué condiciones se produce? | |
| ¿Cambia al variar el orden de los pasos? | |
| ¿Cambia con otra configuración (navegador, pantalla)? | |
| ¿Cambia con otros datos? | |

## Ciclo de vida

```text
Nuevo → Abierto → Asignado → Corregido → (reprueba) → Verificado → Cerrado
                     ├→ Rechazado     └→ Reabierto → Asignado
                     └→ Diferido
```

## Severidad para HU-XXX

| Severidad | Criterio | Ejemplo en esta historia |
|---|---|---|
| Crítica | Impide usar la funcionalidad o expone información sensible | |
| Alta | Incumple una regla de negocio o un criterio | |
| Media | El criterio se cumple parcialmente | |
| Baja | Presentación sin efecto en la regla | |
