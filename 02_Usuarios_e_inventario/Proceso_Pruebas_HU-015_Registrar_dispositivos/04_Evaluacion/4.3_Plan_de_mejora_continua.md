## Proceso del plan de mejora

| Etapa | Qué se hace | Registro |
|---|---|---|
| 1. Análisis de las causas | Identificar el proceso a mejorar, su impacto y las causas de las incidencias. | |
| 2. Propuesta y planificación | Precisar objetivos, analizar soluciones y definir acciones con responsable y fecha. | |
| 3. Implementación y seguimiento | Ejecutar las acciones y comprobar su cumplimiento. | |
| 4. Evaluación | Informar ventajas y desventajas de los resultados. | |
